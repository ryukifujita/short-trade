# 03. 著名投資家 手法カタログ（学習・ルール化対象）

本章は BR-001 に対応する。**書籍・公開インタビュー等で公表されている手法の考え方**を、
`エントリー条件` / `エグジット条件` / `ポジションサイズ` / `適合レジーム` の4要素に分解し、
戦略モジュール化の可否を判定するための棚卸しである。

> **注意事項**
> - 原著者の手法そのものの完全再現ではなく、**公表情報から抽出した一般的原則の実装**である。
> - 裁量要素（板の空気感、材料の質的評価など）は、代替となる定量指標に置き換えるか、
>   置き換え不能な場合は「実装不可（参考原則のみ）」として扱う。
> - 特定個人の売買を模倣・追随することを目的とせず、公開された**考え方**を検証対象とする。

## 3.0 分類軸

| 軸 | 値 |
|---|---|
| 時間軸 | スキャル（秒〜分）／デイ（分〜1日）／スイング（数日〜数週） |
| 方向性 | 順張り（トレンド・ブレイク）／逆張り（平均回帰）／イベント駆動／需給・フロー |
| 適合レジーム | 上昇トレンド／下降トレンド／レンジ／高ボラ／低ボラ |
| 実装容易度 | A（定量化容易）／B（代替指標で可）／C（裁量依存・参考のみ） |

## 3.8 カタログの管理要求

| ID | 要求 | 優先度 |
|---|---|---|
| FR-C01 | 手法カタログは構造化データ（YAML/JSON）として保持し、各エントリに「出典種別・中核アイデア・条件式・必要データ・想定レジーム・実装容易度・実装状況」を持つこと | Must |
| FR-C02 | 新しい手法の追加・改訂の履歴をバージョン管理できること | Must |
| FR-C03 | 各手法と、それを実装した戦略モジュール・バックテスト結果がトレース可能であること | Must |
| FR-C04 | 実装容易度 C（裁量依存）の手法は、代替定量指標の候補と「未実装理由」を明記すること | Should |
