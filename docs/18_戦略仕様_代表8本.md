## 18.1 全戦略に共通する設計判断

### 判断① すべて「当日終値で判定 → 翌営業日9:00の成行」に統一した

| 理由 | 内容 |
|---|---|
| ルックアヘッドが構造的に起きない | 確定足しか参照しないため、未来情報の混入（VR-002）が設計段階で排除される |
| S株の制約と一致する | ザラ場で執行できないため、そもそも日中の判定に意味がない |
| 実装が1本で済む | 戦略ごとに執行タイミングが違うと、検証も運用も複雑になる |
| 通知が1回で済む | 前日20:00の通知に全戦略の指示がまとまる（`docs/15` §15.2） |

**代償**: 終値でシグナルが出てから翌朝まで約17時間空く。**この遅延は平均回帰系（F4）に最も不利**である（18.6）。

### 判断② レジームフィルタを全戦略の共通条件にした

`TOPIX終値 > TOPIX 200日線`（3営業日のヒステリシス付き）を満たさない期間は、**全戦略が買いシグナルを出さない**。
空売りができない以上、下降局面の防御手段はキャッシュポジションだけである（DEC-060）。

### 判断③ 損切りは全戦略で必須、方式は論理ストップに統一

S株には逆指値がない。条件成立を検知したら**次の執行枠で成行売り**する。
想定損失は損切り幅の2倍で見積もる（RM-001a / RM-001b）。

## 18.3 原法からの改変 — ここが最も重要

**8本のうち、原法をほぼ素直に実装できたのは ST-06 と ST-35 だけである。**
残り6本は制約により中核が削られている。何を削ったかを明示しておかないと、
検証で成績が出なかったときに「手法が悪い」のか「削り方が悪い」のかを切り分けられない。

| 戦略 | 削ったもの | 影響の見立て |
|---|---|---|
| **ST-12** | **原法にない損切りを追加した** | Connors 自身が「平均回帰に損切りは不利」と述べている。**意図的に期待値を下げている。** 検証時は損切りあり／なしの両方を計測し、損切りが奪った収益を数字で把握する |
| **ST-38** | **方向の確認を諦めた** | 原法は始値の上下に逆指値を置き、方向を市場に決めさせる。S株では不可能なため「上昇トレンド中だから上だろう」と仮定するしかない。**原法の核が失われている。削除候補の第一位** |
| **ST-09** | **ショート side を捨てた** | 学術的な超過収益の相当部分は下位銘柄のショートに由来する。ロングのみでは市場全体の変動をそのまま受ける |
| **ST-23** | **コンセンサスを使わず対前年同期比で代替** | PEAD の SUE は「市場の期待との差」で定義される。対前年同期比は期待を反映しないため、**サプライズの測り方として明確に劣る** |
| **ST-04** | VCPを機械的に定義／ピラミッディングなし | 原法は目視のパターン認識。検出が原著者の判断と一致しない。買い増しができないぶん期待値も下がる |
| **ST-06** | System2（55日）とユニット追加を捨てた | 原法の収益の相当部分は買い増しに由来する |
| 全戦略 | **ザラ場執行を捨てた（終値判定→翌朝成行）** | F1・F2 には軽微。**F4 には致命的になりうる**（18.6） |
| 全戦略 | **空売りを捨てた** | 下降局面の収益機会がゼロ。レジームフィルタで回避するのみ |

### 実測（2026-09-12、残差相関、30銘柄・インサンプル。`docs/27` §27.4）

予想の表は **書き換えない**（事前登録した数字として残す）。実測は別表で並べる。

| ペア | 予想 | 実測（残差） | 結果 |
|---|---|---|---|
| ST-06 × ST-09 | 0.35 | 0.41 | 予想どおり |
| ST-06 × ST-12 | 0.00 | 0.28 | **外れ**。ST-12 は `close > SMA200` で上昇トレンド中の押し目だけを買うため、トレンド部分を共有する |
| ST-09 × ST-12 | −0.10 | 0.32 | 同上 |
| ST-04 × 各 | 0.45 / 0.65 / 0.05 | 測定不能 | 2取引。ユニバース拡張後に再測定 |

課題3（ST-06 × ST-12 ≈ 0）は成立しなかったが、0.28 は「同一因子」（0.7）からは遠く、**因子分類は保つ**。
外れた理由は分類ではなく予想の側にある（「符号が逆」は F4 の設計がトレンド条件を持つことを見落としていた）。
なお ST-12 自体は往復コストで期待値が消えたため稼働候補から外した（DEC-068）。課題2 は ST-16 の単体結果を待つ。

### 予想から導かれる3つの検証課題

**課題1: ST-04 × ST-09 = 0.65（予想）— F2とF3の分離を壊す最有力候補**
ST-04 のエントリー条件に相対強度（`PCTRANK(return_126d) >= 70`）が含まれるため、**構造的に F3 と重なる**。
0.7 を超えたら、この条件を緩めるか、ST-09 と統合する。

**課題2: ST-12 × ST-16 = 0.70（予想）— F4内の分離が成立するか**
どちらも「下げたところを買う」。絶対閾値（RSI）と銘柄固有分布（乖離率）という測り方の違いが
分離を生むかどうか。0.7以上なら F4 は1本に絞り、成績の良い方を残す。

**課題3: ST-06 × ST-12 ≈ 0.00（予想）— これが成立するかが最重要**
符号が逆の因子どうしなので、0付近か負を期待する。
**ここが低相関でなければ、因子分類そのものが機能していないことになる。**
分散の主軸が消えるため、Phase 3 の設計に入る前に立て直しが必要になる。

## 18.6 この時点で分かっている最大のリスク

> **「終値判定 → 翌朝9:00成行」という統一が、F4（平均回帰）を殺す可能性がある。**

平均回帰は「売られすぎた瞬間」を買う戦略である。終値で条件が成立してから翌朝の始値までに
約17時間あり、その間に反発が始まっていれば、**最も美味しい部分を取り逃した後で買うことになる**。

ST-12 と ST-16 は F4 の2本であり、両方ともこの影響を受ける。両方が機能しなかった場合：

| 失うもの | 内容 |
|---|---|
| 分散の主軸 | F1（ブレイクを買う）と符号が逆の因子がなくなる |
| 残る構成 | F1・F2・F3 はすべて「上がっているものを買う」系統。**実質的に1因子のポートフォリオになる** |

**この場合の代替案**（Phase 2 の結果を見て判断する）:

1. **F5（イベント）を主軸の1つに引き上げる** — ST-23 に加え ST-26（需給イベント）を復帰させる。
   ただし決算・イベントデータの調達（Q-12）が前提。
2. **F6（需給）を週次データで作る** — MK-01（信用残・空売り比率）は週次で無料入手できる可能性がある。
   板・歩み値なしでも需給の軸を作れるか調査する。
3. **F4 を12:30枠・15:30枠に移す** — S株は1日3回執行できる。前場の値動きを見て12:30枠で買えば、
   遅延を17時間から3時間に縮められる。ただし「当日終値判定」の統一を崩すため、
   ルックアヘッド防止の設計を戦略ごとに検証し直す必要がある。

**代替案3が本命だが、統一を崩す代償が大きい。** Phase 2 で F4 の成績を測ってから判断する。
