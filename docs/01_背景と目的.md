# 01. 背景・目的・製品ビジョン

## 1.1 背景と課題

短期売買（デイトレード〜スイングトレード）の分野には、Jesse Livermore、William O'Neil、Mark Minervini、
Linda Raschke、Richard Dennis（タートルズ）といった海外の著名トレーダーから、BNF氏・cis氏・テスタ氏といった
日本の著名個人投資家まで、**書籍やインタビューで語られた多数の手法**が蓄積されている。

しかし、これらを個人が実運用しようとすると次の課題が生じる。

| # | 課題 | 具体的な症状 |
|---|---|---|
| P-1 | 手法が言語化止まりで、検証可能なルールになっていない | 「押し目で買う」「勢いのある銘柄」等、実装できない粒度 |
| P-2 | 手法ごとに得意な相場環境（レジーム）が異なる | 上昇トレンドでは順張りが効くが、レンジでは損切り貧乏になる |
| P-3 | 単一手法への依存でドローダウンが深くなる | 手法の不調期にそのまま資金曲線が沈む |
| P-4 | 裁量判断に感情が混入する | 損切り遅延、利確の早期化、リベンジトレード |
| P-5 | 監視対象が多く、人手ではシグナルを取りこぼす | 東証プライム・スタンダード・グロースで約4,000銘柄 |
| P-6 | 「今いくら儲かっているか」が即座に分からない | 証券会社画面は手数料・金利・税を控除前で表示、戦略別の内訳も不明 |
| P-7 | 過去検証と実運用の乖離 | 過剰最適化、スリッページ・約定滑りの未考慮 |

## 1.2 解決仮説

- **H-1**: 著名手法を「エントリー条件／エグジット条件／ポジションサイズ／適合レジーム」の4要素に分解すれば、
  大半は検証可能なルール（＝戦略モジュール）へ翻訳できる。
- **H-2**: 単一手法ではなく、**相場レジームに応じて複数手法を重み付け合議**させることで、
  期待リターンを大きく損なわずに最大ドローダウンを低減できる。
- **H-3**: 損益を**手数料・金利・税控除後**かつ**戦略別**にリアルタイム表示すれば、
  不調な戦略の停止判断が早まり、実運用の生存確率が上がる。

## 1.3 製品ビジョン

> **「複数の名手の判断を合議制で束ね、規律をもって執行し、結果を即座に見せる。」**

- 名手の判断＝著名投資家手法を実装した**戦略モジュール群**
- 合議制＝相場レジームと直近成績で**動的に重み付けするアンサンブル意思決定**
- 規律＝**例外を許さないリスク管理**（損切り・上限・キルスイッチ）
- 即座に見せる＝**秒以下で更新されるリアルタイム損益**と、**なぜ売買したかの説明**

## 1.4 事業要求（BR）

| ID | 事業要求 | 優先度 | 成功指標 |
|---|---|---|---|
| BR-001 | 著名投資家の短期売買手法を**網羅的に棚卸し**し、そのうち**因子として直交する少数を選抜**して実装する | Must | カタログ60件以上／全件に因子タグ／同時稼働8本以下・因子あたり2本以下／稼働戦略間の平均相関 0.5 以下（`docs/16` §16.4） |
| BR-002 | 複数戦略を組み合わせた売買意思決定を、人手介在なしに自動生成する | Must | シグナル生成〜発注指示までの完全自動率 100%（手動承認モード除く） |
| BR-003 | 保有ポジションの収益額をリアルタイムに可視化する | Must | 価格更新から画面反映まで p95 で 1 秒以内 |
| BR-004 | 単一戦略運用に対し、リスク調整後リターンを改善する | Must | フォワード検証で、最良単一戦略比 最大DD を 20% 以上低減 |
| BR-005 | 過剰最適化を排し、検証結果と実運用の乖離を抑える | Must | ペーパートレード実績とバックテスト期待値の乖離が ±30% 以内 |
| BR-006 | 破滅的損失（口座資金の毀損）を構造的に防止する | Must | 日次損失上限・キルスイッチの発動テストが全ケース成功 |
| BR-007 | 売買根拠を後から説明・監査できる | Should | 全約定の 100% に寄与戦略・条件スナップショットが紐づく |
| BR-008 | 運用者が戦略の追加・停止を、コード変更なしに行える | Should | 設定ファイル／UI からの戦略ON/OFF、パラメータ変更が可能 |

## 1.5 成功の定義（プロダクトとしてのゴール）

1. **Phase 4（少額実弾）** を 3 か月継続し、システム起因の誤発注ゼロ・リスク上限違反ゼロ。
2. 同期間の実現損益が、同一期間のバックテスト期待値の許容レンジ内に収まる。
3. 運用者が「今日いくら勝っているか」「どの戦略が効いているか」を **画面を見て 5 秒以内** に把握できる。

## 1.6 非ゴール（本プロダクトが目指さないこと）

- ミリ秒単位のレイテンシ競争（HFT／マーケットメイク業）には参入しない。
- 「必ず勝つロジック」の発見を目的としない。**期待値がプラスのルール群を、破産しない資金管理で回す**ことを目的とする。
- 第三者資金の運用、投資助言の提供は行わない（`docs/11_法規制と前提制約.md` 参照）。
