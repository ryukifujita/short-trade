# 13. SBI証券 発注API 調査結果（Q-01 への回答）

調査日: 2026-09-10 / 調査方法: Web検索および公開情報の確認

> **重要**: 本調査は公開情報の検索にもとづく。一部の一次情報（SBI証券公式のヘルプ・約款ページ）は
> 本作業環境のネットワーク制限により直接取得できなかった。**実装着手前に、必ず SBI証券へ直接照会し、
> 書面（利用規約・API仕様書）で確認すること。**

## 13.1 結論（サマリ）

| 問い | 結論 | 確度 |
|---|---|---|
| SBI証券は個人向けに株式（現物）の発注APIを公式提供しているか | **確認できない。公式に案内されている株式現物のAPIは見当たらない** | 中〜高 |
| SBI証券が公式に案内しているAPIは何か | **先物・オプション取引API のみ**（2018年5月2日発表、同年提供開始） | 高 |
| 先物・オプションAPIは今回のスコープで使えるか | **使えない**（本件は現物のみ・信用およびデリバティブは対象外） | 高 |
| HYPER SBI 2 に「ローカルAPI（localhost:18080）」があるか | **裏付けが取れない。要直接確認**（後述 13.3） | 低 |
| スクレイピングによる自動発注は選択肢になるか | **不可**。規約違反リスク・仕様変更による破綻リスクが高く、本要求定義では採用しない | 高 |

**したがって、「SBI証券 × 国内株式現物 × 完全自動発注」は、現時点で公式な実現手段が確認できていない。**
この論点は Q-01' として再度の意思決定が必要（13.5 参照）。

## 13.2 確認できた SBI証券の公式API

### 先物・オプション取引API
- 2018年5月2日に「先物・オプション取引におけるAPI提供開始のお知らせ」が発表され、同年5月から提供。
- 先物・オプション取引口座を持つ顧客が対象。先物・オプションサイトの「外部ツール利用設定」で事前設定が必要。
- **対象商品はデリバティブのみ**であり、国内株式現物の発注はできない。
- 出典: [先物・オプション取引におけるAPI提供開始のお知らせ (SBIグループ PDF)](https://www.sbigroup.co.jp/news/pr/pdf/2018/0502_a.pdf) /
  [SBI証券ヘルプ 先物・オプション API設定](https://search.sbisec.co.jp/v2/popwin/help/opfutures/setting_api.html)

## 13.5 意思決定が必要な論点（Q-01' として再提起）

「SBI証券を使う」と「完全自動で発注する」は、現時点で両立が確認できていない。以下から選択が必要。

| 案 | 内容 | メリット | デメリット |
|---|---|---|---|
| **A. SBI証券＋シグナル提示型（半自動）** | SBI証券の口座はそのまま。ツールはシグナル生成・リスク判定・損益追跡までを自動化し、発注のみ人手（スマホ/PCで数クリック） | 口座を変えない。規約リスクなし。手数料無料（ゼロ革命） | 「完全自動」の要求を満たさない。執行タイミングが人に依存 |
| **B. SBIネオトレード証券に取引口座を追加** | 発注はネオトレAPI for Excel 経由で自動化。SBI証券は資産保管・情報収集用として併用 | SBIグループ内。個人で公式に自動発注可能 | Excel/Windows 常駐が前提。手数料体系が SBI証券のゼロ革命と異なる（1注文50円〜、1日100万円以下無料コースあり） |
| **C. 三菱UFJ eスマート証券に口座開設** | kabuステーションAPI（REST）で自動化 | 最も素直なREST API。実装が容易でコミュニティも大きい | SBI証券から離れる。Professionalプラン条件・Windows常駐。個人口座の可否を要確認 |
| **D. SBI証券のHYPER SBI 2 API（存在すれば）** | SBI証券のまま完全自動 | 理想形 | **存在自体が未確認（CR-040）**。確認が取れるまで計画に組み込めない |

> ### 【決定】 **A案（SBI証券のまま半自動）を採用**（2026-09-10）
> 口座はSBI証券のまま、ツールはシグナル生成・リスク判定・記録・損益追跡を担い、発注操作のみ利用者が
> SBI証券 株アプリで行う。詳細な業務フロー・UI要求は `docs/15_UI要求とマルチデバイス対応.md`。
> CR-040（HYPER SBI 2 API の有無確認）は引き続き実施するが、**A案はその結果に依存せず着手できる**ため、
> Phase 1 以降のブロッカーではなくなった。B案／C案への移行性は NFR-080〜082 で担保する。

**（採用前の推奨。参考として残す）まず CR-040 で D の可否を確定させる。D が不可なら、初期資金5万円という規模を踏まえ「A（半自動）で Phase 2〜3 を進め、
戦略の有効性を確認できた段階で B または C へ移行」という順序を推奨する。**
理由は `docs/14_確定した運用前提と影響分析.md` のとおり、資金5万円の段階では執行の自動化よりも
「戦略の期待値がプラスであること」の確認のほうが先に来るため。

## 13.6 SBI証券を利用する場合に有利な点（確認できた事実）

| 項目 | 内容 | 出典 |
|---|---|---|
| 国内株式売買手数料 | 「ゼロ革命」により、オンラインの国内株式（現物・信用）の売買手数料が約定代金にかかわらず無料。国内上場ETF・ETN・REIT・インフラファンドも対象 | [SBI証券 ゼロ革命](https://www.sbisec.co.jp/visitor/zero-revolution) |
| 適用条件 | インターネットコース（またはプランC）で、電子交付サービスの取扱書面の交付方法を**すべて電子交付**に設定していること | [SBI証券FAQ 対象になる条件](https://faq.sbisec.co.jp/answer/64f176ea8e582c2aa5655c2a/) |
| 単元未満株 | S株として1株から売買可能 | [SBI証券FAQ 単元未満株](https://faq.sbisec.co.jp/answer/5f17d6e68c7981001102a0c0/) |

| ID | 要求 | 優先度 |
|---|---|---|
| CR-041 | ゼロ革命の適用条件（インターネットコース、全書面の電子交付設定）を満たしていることを、運用開始前に確認すること | Must |
| CR-042 | 手数料無料は永続的な保証ではないため、料率変更時に純損益計算（PL-002）へ反映できる構成とすること | Must |
