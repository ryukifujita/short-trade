short-trade ／ 画面設計案 v0.1

スマホで受け取り、三タップで返す。

資金5万円・現物のみ・S株による日足スイング運用を前提とした、半自動トレードツールの画面設計案です。 発注操作だけは利用者が SBI証券 株アプリで行うため、本ツールの画面は 「気づく → 判断を確認する → 実行を記録する」の三点に絞って設計しています。

この設計が守っていること

  • 本ツールはSBI証券のログイン情報を一切持たない。発注は利用者がSBI証券 株アプリで行うため、画面上に認証情報を入力する箇所が存在しない。NFR-070
  • 通知から発注済み記録まで3タップ。兼業で、通勤中に片手で操作することを前提に動線を組んだ。FR-319 / UI-020
  • 暫定値と確定値を混ぜない。約定価格が未入力・CSV未取込の損益には必ず暫定バッジを付ける。PL-046
  • 実行率を成績と同じ場所に置く。半自動では人が実行しないことが最大のリスクなので、見えない指標にしない。FR-318
  • 逆指値が置けない事実を隠さない。論理ストップであること、ギャップ込みで想定損失を2倍に見積もっていることを画面上で明示する。RM-001a / RM-001b
これはワイヤーフレームです。数値・銘柄・価格はすべて画面構成を検討するための架空の例であり、実在の推奨や実績ではありません。 配色・余白・文字サイズは実装時に調整する前提の中間忠実度で、確定デザインではありません。 各項目の要求IDは docs/15_UI要求とマルチデバイス対応.md ほかに対応します。 S株の注文締切時刻（7:00 / 10:30 / 13:30）は公開情報に揺れがあるため、実装前に SBI証券の一次情報で確認します（CR-070）。
