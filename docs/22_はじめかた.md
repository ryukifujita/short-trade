# 22. はじめかた（PCでの初回セットアップ）

ターミナルの操作に慣れていない前提で書いています。**3ステップ**です。

---

## ステップ1: コードをPCに入れる

Git を使わずに、ZIP でダウンロードできます。

1. ブラウザで次を開く
   **https://github.com/ryukifujita/short-trade/tree/claude/stock-trading-tool-requirements-d0irut**
2. 緑色の **「Code」** ボタン → **「Download ZIP」**
3. ダウンロードした ZIP を **ダブルクリックして展開**
4. 展開されたフォルダ（`short-trade-claude-stock-trading-tool-requirements-d0irut` のような名前）を、
   **デスクトップなど分かりやすい場所に移動**しておく

> フォルダの中に `start_mac.command` と `start_windows.bat` があれば正しく展開できています。

---

## ステップ2: Python を入れる（入っていなければ）

https://www.python.org/downloads/ を開き、大きなボタンからインストールします。

> **Windows の方へ**: インストール画面の一番下にある
> **「Add python.exe to PATH」に必ずチェックを入れてください。**
> ここを忘れると起動ファイルが Python を見つけられません。

すでに入っていればステップ3へ。分からなければ、そのままステップ3を試してください。
入っていなければ起動ファイルが「Python が見つかりません」と教えてくれます。

---

## ステップ3: 起動ファイルをダブルクリック

### Windows の場合

フォルダの中の **`start_windows.bat`** をダブルクリックするだけです。

> 「WindowsによってPCが保護されました」と出たら、
> **「詳細情報」→「実行」** を押してください。

### Mac の場合

フォルダの中の **`start_mac.command`** を **右クリック → 「開く」** を選びます。
（初回はダブルクリックだと「開発元を確認できないため開けません」と出ます。
右クリックから開くと「開く」ボタンが出るので、それを押してください）

もし「アクセス権がありません」と出る場合は、ターミナルで次の1行を実行してから、もう一度開いてください。

```bash
chmod +x ~/Desktop/short-trade*/start_mac.command
```

---

## 起動ファイルが何をするか

黒い画面（ターミナル）が開き、次を自動でやります。

| 順番 | 内容 | 時間 |
|---|---|---|
| 1 | Python があるか確認 | 数秒 |
| 2 | 専用の作業場所（`.venv`）を作る | 1〜3分（初回のみ） |
| 3 | 必要な部品をインストール | 1〜3分（初回のみ） |
| 4 | **ブラウザに設定画面を開く** | — |

2回目以降は 2・3 が省略され、すぐ設定画面が開きます。

**黒い画面は開いたままにしておいてください。** 閉じると設定画面も止まります。

---

## 設定画面でやること

ブラウザに「J-Quants の接続設定」という画面が出ます。

1. **APIキー** の欄に、J-Quants の APIキーを貼る
   （J-Quants にログイン → ダッシュボード → 「APIキー」の欄。他のツールで
   使っているものをそのまま貼れます）
2. **「接続を確認して、続きを自動で進める」** を押す

> APIキーに有効期限はありません。1週間で切れるのは旧方式のトークンで、
> そちらは 2026年6月に廃止されています（`docs/23`）。

あとは自動です。5〜10分ほどで完了画面が出ます。

| 段階 | 自動でやること |
|---|---|
| 1/3 接続確認 | 認証 → 上場銘柄一覧 → 日足が何年遡れるか → TOPIX の可否（不可なら 1306 で自動代用）→ 決算予定の可否 |
| 保存 | `.env` に保存（Git には入りません。所有者だけが読める権限にします） |
| 2/3 取得 | 指数と代表30銘柄の日足をダウンロード |
| 3/3 基準線 | ST-06（ドンチャン）をスリッページ 0% と 0.1% で実行 |

## 終わったら

フォルダの中の **`data/setup_report.json`** をメモ帳やテキストエディットで開き、
**中身をそのままコピーして報告してください。**

このファイルに認証情報は含まれません（テストで確認済みです）。

**うまくいかなかったとき**は、ブラウザの画面に出ているログの
**いちばん下の行**をそのままコピーして報告してください。

---

## よくあるつまずき

| 症状 | 対処 |
|---|---|
| ブラウザが自動で開かない | ブラウザのアドレス欄に `http://127.0.0.1:8765/` と入力 |
| 「Python が見つかりません」 | ステップ2をやり直す。Windows は「Add python.exe to PATH」のチェックを忘れずに |
| Mac で「開発元を確認できないため開けません」 | ダブルクリックではなく **右クリック →「開く」** |
| 「WindowsによってPCが保護されました」 | 「詳細情報」→「実行」 |
| 黒い画面がすぐ消える | エラーが出ています。もう一度開いて、消える前のメッセージを撮影して報告してください |
| `HTTP 403` が出る | 旧方式（リフレッシュトークン）を貼っていませんか。**ダッシュボードの「APIキー」**を貼ってください |
| 「APIキーが見つかりません」 | 設定画面で入力し直してください。`.env` に保存されます |

## 2回目以降

初回セットアップが済んだら、**`run_mac.command`**（Mac）／ **`run_windows.bat`**（Windows）を使います。

- データは再取得しません（速い）
- 初回だけ決算発表予定日を取得します（数分〜十数分）
- リスク率 1% / 2% × スリッページ 0 / 0.1% の比較表を出し、`data/compare_report.json` に保存します

終わったら `data/compare_report.json` の中身を貼って報告してください。
