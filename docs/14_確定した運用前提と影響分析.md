## 14.2 影響1: 単元株制度と 5万円 の衝突

### 事実
- 国内株式の通常取引は **100株単位**。5万円で単元株を買える銘柄は、株価 **500円以下** に限られる。
- 5万円で1銘柄（例: 400円×100株=4万円）を買うと、**ほぼ全資金が1銘柄に集中**する。

### 帰結
| 論点 | 影響 |
|---|---|
| 分散 | 単元株では実質1銘柄しか持てず、RM-013（同時保有数）・RM-012（セクター分散）が機能しない |
| リスク率 | 1トレードリスク 1%（=500円）を単元株で実現するには、株価400円の銘柄で損切り幅5円（1.25%）が必要。ノイズに対して狭すぎて機能しない。現実的な損切り幅3%では **1トレードリスクは資金の約2.4%** になる |
| ユニバース | 500円以下の低位株に偏る。流動性・値動きの質が悪く、手法カタログの前提（O'Neil、Minervini 等は成長株が前提）と合わない |
| 差金決済 | 現物では同一銘柄・同一資金で **1日1回転まで**（買→売 または 売→買）。資金が1銘柄分しかないため、**実質1日1トレードが上限** |

### 代替案: 単元未満株（S株）
| 事実 | 帰結 |
|---|---|
| 1株から売買可能 | 5万円を **5〜10銘柄に分散できる**（1銘柄5,000〜10,000円） |
| **成行注文のみ。指値・逆指値は不可** | **RM-001（損切り注文の常時設置）が物理的に実現できない** |
| 約定は1日3回（9:00 / 12:30 / 15:30）、注文時間帯により執行タイミングが決まる | ザラ場のシグナルに反応できない。**デイトレード・スキャルピングは成立しない** |
| 同一取引日・同一預り区分・同一銘柄では、各発注タイミングにつき買・売それぞれ1件まで | 分割執行・ピラミッディング（MM-04）が使えない |

出典: [SBI証券 単元未満株（S株）取引ルール](https://search.sbisec.co.jp/v2/popwin/attention/trading/stock_07.html) /
[SBI証券FAQ 単元未満株の買付・売却](https://faq.sbisec.co.jp/answer/5f17d6e68c7981001102a0c0/) /
[差金決済取引の禁止について（立花証券）](https://t-stockhouse.jp/service/rule/profibit.php)

### 推奨する運用形態

> **S株（単元未満株）による、1日1回判定・1日1〜3回執行の「日足スイング」運用。**

理由:
- 5万円で**分散が効く唯一の方法**であり、単一銘柄への全資金集中（実質的な破産リスク）を避けられる。
- 差金決済規制の影響を受けにくい（そもそも日をまたぐ保有が前提）。
- 手法カタログのうち、日足ベースのトレンドフォロー・モメンタム・平均回帰系がそのまま使える。

| ID | 要求（新規） | 優先度 |
|---|---|---|
| CR-050 | 初期スコープの取引単位は **S株（単元未満株）** を既定とし、単元株取引は資金が単元株での適切な分散に足りる水準（目安: 50万円以上）に達するまで採用しないこと | Must |
| CR-051 | 現物の差金決済規制（同一銘柄・同一資金で1日1回転まで）を発注前検査に組み込み、抵触する注文を出さないこと | Must |
| CR-052 | 買付余力を発注前に検査し、受渡日を考慮した資金拘束を管理すること | Must |

## 14.3 影響2: 「損切り注文を常時置く」が成立しない → ロジカルストップへの置換

S株は成行のみのため、RM-001（逆指値の常時設置）を文字通り満たせない。代替として次を定義する。

| ID | 要求（RM-001 の改訂） | 優先度 |
|---|---|---|
| RM-001a | 全ポジションに**損切り価格（論理ストップ）**を必ず設定すること。価格が損切り水準に到達したことを検知したら、**直近の執行タイミングで成行売り注文を発注**すること | Must |
| RM-001b | 論理ストップの執行遅延（最大で判定から翌営業日9:00まで）を前提に、**1トレードリスクは「損切り価格までの損失」ではなく「ギャップを含む想定最大損失」で見積もる**こと。既定では損切り幅の 2 倍を想定損失とする | Must |
| RM-001c | オーバーナイトのギャップリスクを抑えるため、1銘柄あたりの投下額上限を資金の 15〜20% とすること | Must |
| RM-001d | 決算発表日を跨ぐ保有を既定で禁止すること（ギャップリスクが論理ストップの想定を超えるため） | Must |
| RM-001e | 想定を超えるギャップ（例: 損切り幅の3倍以上の逆行）が発生した場合、当該戦略を自動停止し通知すること | Should |

> **これは実質的なリスク許容度の引き上げである。** 逆指値が置けない以上、
> 「損切り価格で必ず止まる」という前提は使えない。この点は運用開始前に明確に認識しておくこと。

## 14.5 影響4: 「完全自動」と 発注API の可否

**【解決済み】A案（半自動）を採用したことで、この論点は解消した。**

当初の D-04（完全自動）は発注APIが利用できて初めて成立するが、`docs/13` のとおり SBI証券に
国内株式現物の個人向け発注APIがあることは確認できなかった。加えて、仮に発注APIがあったとしても
**S株はAPI発注に対応していない可能性が高い**（単元未満株は発注チャネル・執行方式が通常取引と異なるため）。

そこで **発注操作のみを利用者に委ね、それ以外をすべて自動化する A案** を採用した。
業務フロー・通知設計・UI要求は `docs/15_UI要求とマルチデバイス対応.md` に定義する。

| ID | 要求（改訂） | 優先度 |
|---|---|---|
| CR-043 | 将来 B案／C案へ移行する際、**単元未満株がAPI経由で発注可能か**を事前に書面で確認すること | Must（移行時） |
| CR-044 | ~~完全自動が実現できない場合に備え〜~~ → **A案の採用により、半自動モードが主経路となった**（FR-191 を Must 化済み） | 完了 |
| NFR-080 | 「シグナル生成〜リスクゲート」と「執行」を分離し、アダプタ差し替えで自動発注へ移行できること | Must |

### A案を採用したことによる副次的な利点

| # | 利点 |
|---|---|
| 1 | **証券口座の認証情報をツールが一切保持しない**（NFR-070）。漏洩時も資産の直接的な毀損リスクがない |
| 2 | 誤発注による暴走リスクが構造的に存在しない（人が最後に必ず目視する） |
| 3 | SBI証券のゼロ革命（手数料無料）をそのまま享受できる |
| 4 | 証券会社のAPI規約・レートリミットの制約を受けない |
| 5 | 実装量が減り、Phase 2〜3 に早く到達できる |

### A案の弱点と対策

| # | 弱点 | 対策 |
|---|---|---|
| 1 | **人が実行しないとシグナルが空振りする** | 実行率をKPI化（FR-318）、締切60分前通知＋最終リマインド（CR-071） |
| 2 | 損切りの実行が人に依存する | 損切りシグナルは通知優先度を最上位に（FR-303）、実行率を個別監視 |
| 3 | 約定価格が即座に分からない | 暫定計上＋CSV取込による自動補正（FR-315〜FR-317） |
| 4 | 執行タイミングにばらつきが出る | S株はもともと1日3回の一括執行のため、影響は限定的 |

## 14.6 影響5: 収益規模とコスト構造

| 項目 | 試算 |
|---|---|
| 運用資金 | 50,000円 |
| 月次リターンが +3% の場合の月間利益 | 1,500円 |
| 月次リターンが +5% の場合の月間利益 | 2,500円 |
| 売買手数料（SBI証券・ゼロ革命適用時） | 0円 |
| VPS/クラウド（月額1,000円と仮定） | 利益の 40〜67% |

| ID | 要求（新規・C-06 の具体化） | 優先度 |
|---|---|---|
| NFR-060 | Phase 4（少額実弾）までの**月額固定費を 0 円**に抑えること。有料の市場データ購読・有料VPSは採用しない | Must |
| NFR-060' | **条件付き緩和**: Phase 3 の検証で期待値がプラスと確認され、かつ**運用資金が20万円以上**になった時点で、月額1,650円までの有料データを許容する。それ以前の課金は認めない（`docs/19` §19.5） | Must |

> **重要な位置づけの確認**: 資金5万円の段階で得られる金額は小さい。
> この段階の目的は**利益を得ることではなく、「戦略の期待値がプラスであること」と「システムが正しく動くこと」を、
> 実弾で検証すること**である。KPI（`docs/12_受入基準とKPIと用語集.md`）の金額目標より、
> **誤発注ゼロ・上限違反ゼロ・突合差異ゼロ**を優先する。

## 14.8 リアルタイム損益要求への影響

D-01〜D-04 のもとでは、ザラ場のティック単位の損益追跡は**戦略の意思決定には不要**になる（判定は1日1回のため）。
ただし「リアルタイムで収益額が分かる」という当初の要求（BR-003）は、**利用者の把握手段として引き続き有効**である。

| ID | 改訂 | 内容 |
|---|---|---|
| PL-020' | レイテンシ要件の緩和 | 意思決定用途ではないため、価格更新から画面反映まで **p95 ≤ 3秒**（従来1秒）へ緩和してよい。無料データ源の更新間隔に依存するため |
| PL-056 | 表示粒度の明示 | 無料データ源を用いる場合、株価が遅延値である可能性を UI に明示すること（「20分遅延」等） | Must |
| PL-057 | 日次確定値との区別 | ザラ場中の含み損益は参考値であり、確定値は当日の約定・終値ベースであることを明示すること | Must |

損益の**正確性**に関する要求（PL-002 純損益、PL-040 突合、PL-042 約定ベース、PL-043 十進演算）は
**一切緩和しない**。むしろ資金が小さいほど、コストが損益に占める比率は大きくなるため重要度が上がる。
