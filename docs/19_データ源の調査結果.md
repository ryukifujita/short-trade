## 19.1 結論

| 用途 | 推奨するデータ源 | 費用 |
|---|---|---|
| **バックテスト（Phase 1〜3）** | **J-Quants API 無料プラン**（JPX公式） | **0円** |
| 銘柄マスタ | **JPX「東証上場銘柄一覧」**（data_j.xls） | 0円 |
| 長期ヒストリカルの一括取得 | J-Quants 有料プランを**1か月だけ契約して一括取得し、解約** | **一時費用のみ**（Light 1,650円 / Standard 3,300円） |
| 実運用（Phase 4）の当日データ | **未確定。Phase 3 の終わりに決める** | — |

**要点: 「バックテスト用」と「実運用用」は要件がまったく違うので、分けて調達する。**

- バックテストは**過去データさえ揃えばよく、遅延は問題にならない**。→ J-Quants 無料プランで足りる。
- 実運用は**当日の終値が当日中に必要**。→ 無料プランは12週遅延のため使えない。

そして **Phase 4 に進むかどうかは Phase 3 の検証結果で決まる。**
期待値がプラスだと分かる前に月額を払うのは順序が逆なので、**実運用データ源の決定は Phase 3 の終わりまで先送りする。**

## 19.3 候補の評価

| 候補 | 提供元 | 日足 | 銘柄マスタ | 決算日 | 遅延 | 費用 | ライセンス | 評価 |
|---|---|---|---|---|---|---|---|---|
| **J-Quants API 無料** | JPX（公式） | ○ | ○ | ○ | **12週** | 0円 | 公式・明確 | **バックテストの本命** |
| J-Quants Light | JPX | ○ | ○ | ○ | 翌日 | 1,650円/月 | 公式・明確 | 実運用の第一候補。ただし NFR-060 に抵触 |
| J-Quants Standard | JPX | ○ | ○ | ○ | 翌日 | 3,300円/月 | 公式・明確 | 5年分の履歴。一括取得用として1か月だけ契約する案 |
| **JPX 東証上場銘柄一覧** | JPX（公式） | — | ○ | — | 月次 | 0円 | 公式配布 | **銘柄マスタはこれで足りる** |
| yfinance（Yahoo Finance） | 非公式 | ○ | △ | △ | 15分程度 | 0円 | **グレー** | 公式APIではなく、Yahoo の規約は自動取得を制限している。**推奨しない** |
| stooq.com | 民間（ポーランド） | ○ | △ | ✕ | 日次 | 0円 | **要確認** | 日本株の日足CSVを配布。ライセンス条件の確認が必要 |
| SBI証券のツールからCSV出力 | SBI証券 | ○ | ○ | — | 当日 | 0円 | 自己口座経由 | 規約内の可能性は高いが、**全銘柄分を毎日出すのは非現実的** |

### yfinance を推奨しない理由

無料で日本株の日足が取れ、広く使われている。しかし **Yahoo Finance は公式APIを提供しておらず**、
yfinance は事実上のスクレイピングである。Yahoo の利用規約は自動取得を制限しており、
**規約違反のリスクを負ったまま運用の土台にすることは、本プロジェクトの方針（CR-023 / DR-021）と整合しない。**

検証段階の相互チェック（J-Quants のデータが正しいかの照合）に限って使うのは許容範囲だが、
**運用の唯一のデータ源にはしない。**

## 19.4 推奨する構成

### Phase 1〜3（バックテスト）

```
① 銘柄マスタ    JPX「東証上場銘柄一覧」（data_j.xls）を月次で保存 → 各時点の状態を再現（VR-004 生存者バイアス対策）
② 日足OHLCV     J-Quants API 無料プラン
③ TOPIX         J-Quants で取れない場合は TOPIX連動ETF（1306）の日足で代用
④ 決算発表日     J-Quants API（無料プランに含まれる）
```

**③の代用案は重要である。** TOPIX指数そのものが無料プランで取れない場合でも、
**1306 は個別銘柄として日足が取れる**。レジーム判定（200日線との位置関係）には十分な精度がある。
指数そのものとの誤差は、バックテスト時に両方で比較して確認する。

### ヒストリカルの一括取得

無料プランで遡れる期間が短い場合（§19.7 の未確認事項）、次の方法を推奨する。

> **有料プラン（Standard 3,300円）を1か月だけ契約し、5年分を一括ダウンロードして解約する。**

- VR-015（バックテストに最低5年、可能なら10年）を満たせる。
- **一時費用であり、月額固定費ではない**ため NFR-060 の趣旨に反しない。
- ただし **解約後も取得済みデータを保持・利用してよいか**を利用規約で必ず確認する（§19.7）。

### Phase 4（実運用）— 決定を先送りする

当日の終値が当日中に必要になるため、無料プランでは動かない。選択肢は次の4つ。

| 案 | 内容 | 月額 | 5万円に対する年間比率 |
|---|---|---|---|
| **A** | J-Quants Light を契約 | 1,650円 | **年19,800円＝資金の40%** |
| **B** | stooq 等の無料CSVを使う | 0円 | 0% |
| **C** | ユニバースを日経225等に絞り、SBI証券のツールから当日データを取得 | 0円 | 0% |
| **D** | Phase 4 に進まない（検証結果が悪ければ） | 0円 | — |

**資金5万円では案Aは成立しない。** 月1,650円は資金の3.3%であり、
月次リターン+3%を丸ごと食う。**有料データが合理的になるのは、資金が概ね20万円を超えてからである。**

したがって Phase 4 の現実的な選択は **B か C**。とくに **C（ユニバースを絞る）は副次的な利点が大きい**：

- 対象を日経225やTOPIX500に絞れば、データ量が 4,000銘柄 → 225〜500銘柄になり、取得も検証も軽くなる。
- **低位株・低流動性銘柄が自動的に除外される**ため、`docs/14` で指摘したユニバースの質の問題が解消する。
- ST-09（クロスセクショナル・モメンタム）は母集団が小さくなると効きが落ちる可能性があり、
  これは Phase 2 のバックテストで「全市場」と「日経225限定」を比較して確かめる。

| ID | 要求（新規） | 優先度 |
|---|---|---|
| DR-030 | バックテストは**全市場ユニバース**と**日経225等の絞り込みユニバース**の両方で実施し、成績差を記録すること。実運用のユニバースはこの結果とデータ調達性の両方で決めること | Must |
| DR-031 | データ源を差し替え可能なアダプタとし、**J-Quants / CSV / 手動投入**を同じ内部形式に正規化すること（FR-109） | Must |
| DR-032 | 取得したデータはローカルに永続化し、**同じ検証が再実行できる**こと。データのバージョン（取得日・ソース）を記録すること（VR-006） | Must |

## 19.5 NFR-060（月額固定費0円）の扱い

現行の要求は「Phase 4 までの月額固定費を0円に抑える」である。調査の結果、これは**維持できる**。

| フェーズ | 月額 | 内訳 |
|---|---|---|
| Phase 1〜3 | **0円** | J-Quants 無料＋JPX公式ファイル |
| ヒストリカル一括取得 | 一時 3,300円 | 1か月だけ契約して解約（月額固定費ではない） |
| Phase 4 | **0円を目標** | 案B（無料CSV）または案C（ユニバース絞り込み） |

| ID | 改訂 | 内容 |
|---|---|---|
| NFR-060' | 条件付きの緩和 | 月額固定費は0円を原則とする。ただし **Phase 3 の検証で期待値がプラスであることが確認され、かつ運用資金が20万円以上**になった時点で、月額1,650円までの有料データを許容する。**それ以前の課金は認めない** |

## 19.6 ライセンスと規約の整理（DR-021 対応）

| データ | 提供元 | 確認済みの条件 | 本プロジェクトでの扱い |
|---|---|---|---|
| J-Quants API | JPX | 個人向けサービス。プランごとにデータ期間と遅延が異なる | 利用規約を一次情報で確認のうえ契約 |
| 東証上場銘柄一覧 | JPX | 「投資勧誘を目的としたものではなく、情報の完全性を保証しない」旨の注記あり。無料配布 | 自己の分析用途に限定して使用。再配布しない |
| TOPIX | JPX | 指数はJPXの知的財産。再配布に制限 | 自己利用のみ。値をリポジトリにコミットしない |
| yfinance | 非公式 | Yahoo の規約は自動取得を制限 | **運用データ源としては採用しない** |

| ID | 要求（新規） | 優先度 |
|---|---|---|
| DR-033 | 取得した市場データを**リポジトリにコミットしない**こと。`.gitignore` でデータディレクトリを除外すること | Must |
| DR-034 | データ源ごとのライセンス条件を `config/data_sources.yaml` に記録し、条件に反する保存・共有をしないこと | Must |
