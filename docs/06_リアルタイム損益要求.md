# 06. リアルタイム損益（P&L）可視化要求

本章は BR-003 に対応する。「リアルタイムで収益額が分かる」ことは本ツールの中核価値であり、
**正確性**（証券会社の残高と一致する）と**即時性**（秒以下で更新）の両立を要求する。

> **改訂（2026-09-10）**: 1日1回判定の日足スイング運用となったため、損益表示は**意思決定用途ではなく利用者の把握用途**になる。
> レイテンシ要件の緩和（PL-020' p95 ≤ 3秒）と、遅延データ・確定値の明示（PL-056 / PL-057）は
> [`docs/14_確定した運用前提と影響分析.md` §14.8](14_確定した運用前提と影響分析.md) を参照。
> **正確性に関する要求（PL-002 / PL-040 / PL-042 / PL-043）は緩和しない。** 資金が小さいほどコスト比率が上がるため重要度はむしろ高い。

## 6.1 損益の定義

| 用語 | 定義 |
|---|---|
| 含み損益（Unrealized P&L） | 保有建玉について、`(評価価格 − 平均取得単価) × 数量 × 方向`。空売りは符号反転 |
| 実現損益（Realized P&L） | 決済済み取引の売却代金 − 取得原価 |
| 総損益（Gross P&L） | 含み損益 + 実現損益（コスト控除前） |
| 純損益（Net P&L） | 総損益 − 手数料 − スプレッド／スリッページ実績 − 信用金利 − 貸株料 − 逆日歩 − 消費税 |
| 税引後損益（After-tax、参考値） | 純損益 − 譲渡益課税相当額（概算・参考表示） |
| R倍数 | 実現損益 ÷ そのトレードの初期リスク額 |

| ID | 要求 | 優先度 |
|---|---|---|
| PL-001 | 含み損益・実現損益・純損益を明確に区別して表示すること | Must |
| PL-002 | 純損益の算出に、手数料・信用金利・貸株料・逆日歩・消費税を含めること | Must |
| PL-003 | 平均取得単価の計算方法（移動平均法／総平均法）を明示し、証券会社の方式と整合させること | Must |
| PL-004 | 税引後損益は「概算・参考値」であることを明示し、確定値でない旨を UI に表示すること | Must |
| PL-005 | 外貨建て銘柄を扱う場合、為替評価損益を分離表示すること | Could |

## 6.2 評価価格の決定

| ID | 要求 | 優先度 |
|---|---|---|
| PL-010 | 評価価格は既定で「直近約定値（現在値）」を用いること | Must |
| PL-011 | 評価価格を「仲値（bid/ask 中値）」「反対売買可能価格（買建なら最良買い気配）」へ切替可能とすること | Should |
| PL-012 | 気配が消失・板が薄い場合は直近有効値を保持し、`stale` 表示で古さ（経過秒数）を明示すること | Must |
| PL-013 | ストップ高／安・売買停止中は評価価格の扱いを明示（直近値固定＋警告表示） | Must |

## 6.3 リアルタイム性

| ID | 要求 | 優先度 |
|---|---|---|
| PL-020 | 価格更新から画面反映までの遅延は p95 で 1 秒以内、p99 で 2 秒以内であること | Must |
| PL-021 | 更新は差分配信（プッシュ）とし、全件ポーリングに依存しないこと | Must |
| PL-022 | 高頻度更新時は表示レートを間引く（例: 4〜10Hz）が、内部計算は間引かないこと | Should |
| PL-023 | 画面を閉じている間の損益も継続的に記録され、再表示時に欠落がないこと | Must |
| PL-024 | 通信断時は「切断中・最終更新時刻」を明示し、古い数値を現在値のように見せないこと | Must |

## 6.4 集計軸と指標

| ID | 要求 | 優先度 |
|---|---|---|
| PL-030 | 集計軸として、口座全体／戦略別／銘柄別／セクター別／時間帯別／保有期間別を提供すること | Must |
| PL-031 | 期間軸として、当日／今週／今月／今年／累計／任意期間を切替できること | Must |
| PL-032 | パフォーマンス指標として、勝率・平均利益・平均損失・プロフィットファクタ・期待値・平均R・最大連敗・最大ドローダウンを表示すること | Must |
| PL-033 | リスク調整指標（シャープレシオ、ソルティノレシオ、カルマーレシオ）を表示すること | Should |
| PL-034 | 資金曲線（エクイティカーブ）とドローダウン曲線を時系列グラフで表示すること | Must |
| PL-035 | 戦略別の寄与度（当日純損益に占める各戦略の内訳）を表示すること | Must |
| PL-036 | 取引コスト（手数料・金利・スリッページ）の内訳と、総損益に対する比率を表示すること | Should |
| PL-037 | 実現スリッページ（想定価格と約定価格の差）を計測・集計すること | Should |

## 6.5 正確性・突合

| ID | 要求 | 優先度 |
|---|---|---|
| PL-040 | 日次で、証券会社の残高・建玉・実現損益と自システムの値を突合し、差異を検出・通知すること | Must |
| PL-041 | 差異の許容閾値を設定でき、超過時は該当戦略の新規建てを停止できること | Should |
| PL-042 | 損益計算はすべて約定ベースで行い、シグナル価格や想定価格で代用しないこと | Must |
| PL-043 | 金額計算は浮動小数点誤差を避ける実装（十進固定小数点等）を用いること | Must |
| PL-044 | コーポレートアクション（分割・併合・配当・株式移転）発生時に、取得単価と損益を正しく調整すること | Must |
| PL-045 | 損益スナップショットを一定間隔で永続化し、任意時点の損益を後から再現できること | Should |

## 6.6 ダッシュボードの表示要求

| ID | 要求 | 優先度 |
|---|---|---|
| PL-050 | 最上部に「当日純損益（金額と口座比%）」を最大サイズで常時表示すること（5秒以内に把握できること） | Must |
| PL-051 | 損益の符号を色で区別し、色覚多様性に配慮した配色（形状・符号の併用）とすること | Should |
| PL-052 | 建玉一覧に、銘柄・数量・平均単価・現在値・含み損益・R進捗・損切り価格・帰属戦略・保有時間を表示すること | Must |
| PL-053 | 当日のリスク使用率（日次損失上限に対する消化率、ポートフォリオ・ヒート）をゲージ表示すること | Must |
| PL-054 | モバイル画面でも当日損益・建玉・キルスイッチにアクセスできること | Should |
| PL-055 | 表示通貨・単位（円、千円、万円）を切替できること | Could |
